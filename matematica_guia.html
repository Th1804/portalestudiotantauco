Números Racionales

Un número racional es todo número que se puede expresar como fracción p/q, donde p y q son enteros y q ≠ 0.

Definición

Un número racional es cualquier número que puede escribirse como una fracción p/q donde p (numerador) y q (denominador) son números enteros, y q ≠ 0.

Forma general ℚ = { p/q | p, q ∈ ℤ, q ≠ 0 }
Tipos

Fracción propia

El numerador es menor que el denominador.

3/4   1/2   7/10

Fracción impropia

El numerador es mayor o igual al denominador.

5/3   9/4   7/2

Número mixto

Parte entera + fracción propia.

1½ = 3/2   2¾ = 11/4
Recta numérica
Decimal finito → Fracción

El denominador es una potencia de 10 según los decimales.

Ejemplo
0,75 → 75/100 → 3/4 (simplificar ÷25)
0,125 → 125/1000 → 1/8 (simplificar ÷125)
1,6 → 16/10 → 8/5 (simplificar ÷2)
Decimal periódico puro → Fracción

Si el periodo empieza justo después de la coma:

1
Llama x al decimal: x = 0,333...
2
Multiplica por 10 (1 cifra en el periodo): 10x = 3,333...
3
Resta ambas ecuaciones: 10x − x = 3,333... − 0,333... → 9x = 3
4
Despeja: x = 3/9 = 1/3 ✓
Otro ejemplo: 0,272727...
x = 0,272727...
100x = 27,2727... (periodo = 2 cifras → ×100)
99x = 27 → x = 27/99 = 3/11
Fracción → Decimal

Divide numerador ÷ denominador. Si la división termina → decimal finito. Si se repite → periódico.

Ejemplos
3/4 = 3 ÷ 4 = 0,75 (finito)
1/3 = 1 ÷ 3 = 0,333... (periódico puro)
5/6 = 5 ÷ 6 = 0,8333... (periódico mixto)
Mismo denominador
Fórmulaa/c ± b/c = (a ± b)/c
Ejemplo
3/7 + 2/7 = 5/7
5/8 − 3/8 = 2/8 = 1/4
Distinto denominador
Fórmula (mcm)a/b ± c/d = (ad ± bc)/bd
Ejemplo
1/3 + 1/4 = 4/12 + 3/12 = 7/12
2/5 − 1/3 = 6/15 − 5/15 = 1/15
Pasos para sumar/restar con distinto denominador
1
Encuentra el mínimo común múltiplo (mcm) de los denominadores.
2
Convierte cada fracción al denominador común multiplicando arriba y abajo.
3
Suma o resta los numeradores. El denominador no cambia.
4
Simplifica dividiendo por el MCD si es posible.
Multiplicacióna/b × c/d = (a·c)/(b·d)
Ejemplo
2/3 × 3/4 = 6/12 = 1/2
−5/6 × 3/10 = −15/60 = −1/4
División (invertir y multiplicar)a/b ÷ c/d = a/b × d/c
Ejemplo
3/4 ÷ 1/2 = 3/4 × 2/1 = 6/4 = 3/2
2/5 ÷ 4/3 = 2/5 × 3/4 = 6/20 = 3/10
Para dividir fracciones, NUNCA dividas directamente. Siempre invierte la segunda fracción y multiplica.

Potencias

Una potencia es una multiplicación repetida de un número por sí mismo.

Estructura an = a × a × a × ... × a  (n veces)

Base (a)

El número que se multiplica repetidamente. Puede ser entera, racional o decimal.

En 3⁴: base = 3

Exponente (n)

Indica cuántas veces se multiplica la base por sí misma.

En 3⁴: expo = 4

Potencia

El resultado de la operación completa.

3⁴ = 81
Casos especiales del exponente
a⁰
Exponente cero → siempre 1
a⁰ = 1  (con a ≠ 0)
5⁰ = 1  |  (−3)⁰ = 1  |  (2/3)⁰ = 1
a¹
Exponente uno → la propia base
a¹ = a
7¹ = 7  |  (−4)¹ = −4
a⁻ⁿ
Exponente negativo → inverso de la potencia
a⁻ⁿ = 1/aⁿ
2⁻³ = 1/8  |  (1/3)⁻² = 9
Base racional
Potencia de fracción(p/q)n = pn/qn
Ejemplos
(2/3)² = 2²/3² = 4/9
(−1/2)³ = (−1)³/2³ = −1/8
(3/4)⁻² = (4/3)² = 16/9
Cuidado con el signo: (−2)² = +4 porque se eleva todo al cuadrado. Pero −2² = −4 porque el signo NO está dentro del paréntesis.
P1
Producto de potencias (misma base)
aᵐ · aⁿ = aᵐ⁺ⁿ
3² · 3⁴ = 3⁶ = 729  |  x³ · x⁵ = x⁸
P2
Cociente de potencias (misma base)
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
2⁶ ÷ 2² = 2⁴ = 16  |  x⁷/x³ = x⁴
P3
Potencia de potencia
(aᵐ)ⁿ = aᵐ·ⁿ
(2³)⁴ = 2¹²  |  (x²)⁵ = x¹⁰
P4
Potencia de un producto
(a · b)ⁿ = aⁿ · bⁿ
(2·3)⁴ = 2⁴·3⁴ = 16·81 = 1296
P5
Potencia de un cociente
(a/b)ⁿ = aⁿ/bⁿ
(3/5)² = 9/25
P6
Exponente negativo
a⁻ⁿ = 1/aⁿ  y  (a/b)⁻ⁿ = (b/a)ⁿ
5⁻² = 1/25  |  (2/3)⁻³ = (3/2)³ = 27/8
P7
Exponente cero
a⁰ = 1  (a ≠ 0)
100⁰ = 1  |  (−7)⁰ = 1  |  π⁰ = 1

Crecimiento y Decrecimiento Exponencial

Una función exponencial crece (o decrece) multiplicándose por un factor constante en cada paso.

Forma generalf(x) = a · bˣ   donde a = valor inicial, b = base (factor de cambio)

📈 Crecimiento exponencial

Si b > 1, la función crece. Cada vez que x aumenta en 1, f(x) se multiplica por b.

f(x) = 2ˣ → crece

📉 Decrecimiento exponencial

Si 0 < b < 1, la función decrece. Cada paso multiplica por una fracción menor que 1.

f(x) = (1/2)ˣ → decrece

Visualización
Fórmula en contexto
Modelo generalf(t) = valor_inicial × factort
Problema 1 — Bacterias (crecimiento)
Una bacteria se duplica cada hora. Hay 100 al inicio. ¿Cuántas hay después de 5 horas?

f(t) = 100 × 2t
f(5) = 100 × 2⁵ = 100 × 32 = 3200 bacterias
Problema 2 — Radioactividad (decrecimiento)
Una sustancia pierde la mitad de su masa cada año. Hay 200 g. ¿Cuánto queda en 4 años?

f(t) = 200 × (1/2)t
f(4) = 200 × (1/16) = 12,5 g
Cómo identificar si es exponencial
✓
La variable está en el exponente
f(x) = 3ˣ → exponencial  |  f(x) = x³ → NO es exponencial (es potencial)
✓
Crece/decrece multiplicándose por un factor fijo
Si cada paso suma → lineal. Si cada paso multiplica → exponencial.

Multiplicación de Términos Algebraicos

Antes de los productos notables, domina la multiplicación entre monomios y entre monomio y polinomio.

Coeficiente

El número que acompaña a la parte literal.

En 5x²: coef. = 5

Parte literal

Las variables con sus exponentes.

En 5x²: lit. = x²

Grado

La suma de los exponentes de las variables.

3x²y³ → grado 5
Multiplicar monomios
1
Multiplica los coeficientes entre sí.
2
Multiplica las partes literales: suma los exponentes de la misma variable (propiedad P1).
3
Aplica regla de signos: + × + = +  |  − × − = +  |  + × − = −
Ejemplos
3x² · 4x³ = (3·4) · x²⁺³ = 12x⁵
−2ab² · 5a²b = (−10) · a¹⁺² · b²⁺¹ = −10a³b³
(−3x)(−4x²y) = 12x³y
Monomio por polinomio (distributiva)
Propiedad distributivak(a + b + c) = ka + kb + kc
Ejemplo
3x(2x² − 4x + 1)
= 3x·2x² + 3x·(−4x) + 3x·1
= 6x³ − 12x² + 3x

Productos Notables

Son multiplicaciones especiales entre binomios cuyo resultado tiene una forma fija que conviene memorizar.

Truco: Los productos notables son atajos. En vez de multiplicar todo término a término, aplicas directamente la fórmula. El resultado siempre tiene la misma estructura.
Fórmula(a + b)² = a² + 2ab + b²
¿Cómo se deduce?
1
(a + b)² = (a + b)(a + b)
2
Distributiva: = a·a + a·b + b·a + b·b
3
Simplificar: = a² + 2ab + b²
Cómo recordarlo
Ejemplos resueltos
Ejemplos
(x + 3)² = x² + 2·x·3 + 3² = x² + 6x + 9
(2a + 5)² = (2a)² + 2·2a·5 + 5² = 4a² + 20a + 25
(3x + 2y)² = 9x² + 12xy + 4y² = 9x² + 12xy + 4y²
(x + 1/2)² = x² + x + 1/4 = x² + x + 1/4
(x + 3)² ≠ x² + 9. El término del medio 2ab nunca se puede olvidar.
Fórmula(a − b)² = a² − 2ab + b²
Diferencia clave vs. el anterior: el único cambio es el signo del término del medio: −2ab en vez de +2ab. ¡El último término b² siempre es positivo!
Ejemplos
(x − 4)² = x² − 2·x·4 + 4² = x² − 8x + 16
(3a − 2)² = 9a² − 12a + 4 = 9a² − 12a + 4
(5x − y)² = 25x² − 10xy + y² = 25x² − 10xy + y²
(1/2 − x)² = 1/4 − x + x² = x² − x + 1/4

Fórmula(a + b)(a − b) = a² − b²
¿Por qué desaparece el término del medio?
1
(a + b)(a − b) = a·a + a·(−b) + b·a + b·(−b)
2
= a² − ab + ab − b²
3
Los términos −ab y +ab se cancelan: a² − b²
Pista mnemotécnica: "suma por diferencia" → los términos del medio se anulan, queda cuadrado del primero menos cuadrado del segundo.
Ejemplos
(x + 5)(x − 5) = x² − 25 = x² − 25
(2a + 3)(2a − 3) = 4a² − 9 = 4a² − 9
(x + y)(x − y) = x² − y²
(3x + 7)(3x − 7) = 9x² − 49 = 9x² − 49
Aplicación: cálculo mental rápido
Truco mental con números
21 × 19 = (20+1)(20−1) = 20² − 1² = 400 − 1 = 399
53 × 47 = (50+3)(50−3) = 2500 − 9 = 2491
Propiedad distributivak(a + b) = ka + kb
Ejemplos numéricos
3(x + 4) = 3x + 12
−2(5a − 3) = −10a + 6
x²(x − 1) = x³ − x²
2ab(3a² + b − 4) = 6a³b + 2ab² − 8ab
Al multiplicar por un número negativo, todos los signos del paréntesis cambian. −2(x − 3) = −2x + 6, ¡no −2x − 6!
